# SalesCalc

SalesCalc — это офлайн-приложение для Android, предназначенное для учета и анализа сделок по перепродаже техники. Приложение помогает вести историю покупок и продаж, а также рассчитывать финансовые показатели по каждому товару.

## Что умеет приложение

- Калькулятор прибыли: рассчитывает чистую прибыль, маржу и ROI (окупаемость вложений) по каждой сделке.
- Учет расходов по категориям: приложение позволяет добавлять специфические расходы для разных типов товаров:
  - iPhone: разблокировка iCloud, замена аккумулятора, состояние экрана.
  - Android: прошивка, замена комплектующих.
  - Комплектующие ПК: обслуживание видеокарт, проверка на майнинг.
  - Сборки ПК: стоимость сборки, настройки ОС и тестов.
- Общие расходы: учитывается комиссия Авито, доставка и прочие затраты.
- История и статусы: все сделки сохраняются в базе данных. Есть возможность сохранять черновики и отслеживать товары, которые находятся в продаже слишком долго (более 14 дней).
- Статистика: отображает суммарную прибыль, среднюю маржу и графики по категориям товаров.
- Экспорт данных: возможность выгрузить всю историю сделок в формат CSV.
- Конфиденциальность: приложение работает полностью без доступа к интернету. Все данные хранятся локально на устройстве.

## Как установить

В проекте настроена автоматическая сборка. Чтобы скачать готовый файл приложения (APK):
1. Перейдите во вкладку Actions в верхней части страницы этого репозитория.
2. Выберите последнюю успешную сборку (отмечена зеленой галочкой).
3. Внизу страницы в разделе Artifacts скачайте архив SalesCalc-APK.
4. Распакуйте архив и установите файл app-debug.apk на ваш Android-смартфон.

Приложение написано на Kotlin с использованием Jetpack Compose и Room.
